# Rust Fundamentals Journey

My Rust learning journey through Duke's Rust Fundamentals course (Coursera).

## What's here
Practice exercises organized by topic, each as its own small program.
Currently covers: control flow (if/else if/else), shadowing, 
if/else as expressions, and type-shadowing.

## Structure
Each numbered folder matches a course module. Inside, exercises live
in `src/bin/`, one file per concept, runnable independently with
`cargo run --bin <filename>`.
